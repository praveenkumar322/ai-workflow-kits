# Instagram Content Machine

Adapted by E82 Studios (@e82studios) from a public "Claude prompts for Instagram growth" thread. Seven prompts run as one workflow: blueprint, 100 ideas, 30-day calendar, Reel scripts, growth system, follower-to-client funnel and competitor review.

## Install

- Claude Code: copy `claude/skills/instagram-content-machine/` into your project's `.claude/skills/`.
- Codex: copy `codex/skills/instagram-content-machine/` into your project's `.agents/skills/`.

## Rules

- Drafts only. A person posts, schedules and sends every DM.
- No invented follower counts, results or benchmarks. Use the account's own Insights exports.
- No follow/unfollow, engagement pods, bought followers, scraping or bulk automated DMs.

## Evidence on handover

The drafts folder path, a source for every number, and a plain statement that nothing was posted or sent.
